
# Calculadora

A calculadora foi feita com a estrutura de repetição WHILE com lista, assim, permitindo o usuário executar quantas operações ele quiser.

Pra não ter que fazer vários if/elifs, eu usei a lista para guardar as opções de 1 a 4, assim, se o o usuário digitar um dos números dentro da lista, ele vai executar a operação desejada, se não, ele vai receber um erro dizendo para tentar novamente e se quiser sair é só digitar a opção 5.

A calculadora é bem simples e possui 4 operações.

1. Adição
2. Subtração
3. Multiplicação
4. Divisão



## Rodando o script

Para executar o arquivo SH é necessário usar o ide bash e então digitar ./calculadora.sh
